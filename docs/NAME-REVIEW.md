# Initial name screen — 18 October 2026

This is an initial public-source check, not completed registry clearance. No names have been changed as part of the screen.

## Identified collision

**Altın Pusula** is already used for the Türkiye Halkla İlişkiler Derneği awards, and for a published finance app. It must not be described as an unused or guaranteed-clear invented name. The game team is unrelated; this does not by itself establish infringement or registration scope, but it is a concrete reason to review/replace the name before a formal launch.
